# Проверить полноту сохранения и восстановления NBT сущностей

Status: implemented (175 unit tests and real Paper restart checks passed for 95 types)
GitHub: https://github.com/CheckSelfy/Bake-Mechanisms/issues/22
Branch: feature/22-entity-nbt-audit

## Требования

- Матрица заявленных типов сущностей и проверяемых свойств; по запросу пользователя расширена на живых существ.
- UUID, координаты, направление взгляда, имя, PDC; здоровье, возраст, экипировка и свойства мобов.
- Полные предметы в транспорте и выпавших предметах, включая индивидуальные компоненты.
- Группы транспорта/пассажиров без дублирования и потери участников.
- Восстановление сохранённого снимка после настоящего штатного перезапуска сервера.
- Неподдерживаемые типы/свойства отклоняются до изменения мира; ограничения документируются.

- По запросу пользователя расширена поддержка: 91 живой тип закреплённого Paper API (кроме дракона Края)

  обычных smoke-маркеров стазиса. Ручной клиент для этого аудита не требуется.
