# Декоративный слайм-заполнитель стазиса

Status: implemented
GitHub: https://github.com/CheckSelfy/Bake-Mechanisms/issues/32
Branch: feature/32-slime-stasis-filler
Base: main 288428a

## Требования

- Полностью заполнить исходный кубоид обычными блоками, без выхода за его границы.
- Детерминированные зелёная многотекстурная оболочка, плотная сердцевина и одно симметричное лицо.
- Независимое масштабирование по трём осям; упрощение для маленьких регионов.
- Настраиваемые палитра и рисунок; безопасные материалы без отскока, липкости, тиков и block entities.
- Сохранять оформление/ориентацию вместе со стазисом; старые бедроковые снимки восстанавливаются.
- Сохранить защиту, порядок сохранения снимка перед изменением мира, rollback и выходные контейнеры.
- Проверить 3×3×3, 5×5×5, 10×10×10, 20×20×20, 15×5×10, 5×20×5, 30×5×3, 2×2×2,
  чётные/нечётные размеры, защиту, рестарт и восстановление.

## Решение

Палитра оболочки — окрашенное стекло: без отскока и липкости slime blocks, без появления мобов
на верхних блоках. Плотные акценты и подложка лица находятся внутри. Никаких сущностей или анимаций.
Рисунок вычисляется по локальным зеркальным координатам. Лицо выбирает широкую вертикальную грань
при автоматической ориентации; выбранное направление и версия алгоритма сохраняются в манифесте.

## Comments

- Требования скопированы из GitHub #32; исходный issue не изменялся.
- Последующее улучшение: `AUTO` ориентирует лицо по большинству выходных контейнеров, считая
  двойной сундук одним контейнером. Равенства разрешаются детерминированно с предпочтением широкой
  грани. Явная ориентация конфига и сохранённое оформление существующих слаймов не меняются.
- Реализованы алгоритм 1, два узора, безопасная настраиваемая палитра, ориентация лица и манифест
  формата 3; старые форматы 1/2 читаются с bedrock-оформлением. Восстановление снимка не зависит
  от текущей палитры, при ошибке возвращается сохранённый вид заполнителя.
- Прошли unit-тесты, `build`, `stasisSmoke`, `entityNbtSmoke`, протокольное создание/посещение галереи
  после двух запусков сервера и полный цикл четырёх настоящих ферм кактуса/тростника.
- Native-проверка девяти размеров включает реальную отменённую попытку поршня, взрыв, сохранение
  выходного контейнера, нестандартную сохранённую палитру и откат после частичной ошибки восстановления.
- Фронтальная схема из реальных серверных блоков просмотрена. Игровая визуальная приёмка текстур
  и прозрачности доступна пользователю через `/slimegallery 1..9`; протокольный тест не выдаётся
  за просмотр Minecraft-клиента. [Инструкция](../../../docs/testing/slime-filler.md).
