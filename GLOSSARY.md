# Bake Mechanisms

Предметная область проекта — снижение нагрузки Minecraft-сервера за счёт замены работы автоферм эквивалентным производством ресурсов.

## Language

**Автоферма без входа**:
Автоферма, которая производит предметы без потребления входных ресурсов и помещает результат в выходной контейнер. Фермы опыта не относятся к поддерживаемой области.
_Avoid_: Любая ферма, бесконечный генератор

**Выходной контейнер**:
Отдельный от заменяемого механизма контейнер, который сохраняется в мире во время стазиса и представляет наблюдаемый результат работы фермы.
_Avoid_: Выход, результирующий сундук

**Размеченная ферма**:
Автоферма без входа, для которой выделены один кубоид механизма и один или несколько выходных контейнеров. Профиль производства измеряется отдельно для каждого выходного контейнера.
_Avoid_: Сложное выделение, область

**Имя фермы**:
Необязательное, чувствительное к регистру имя размеченной фермы, уникальное среди ферм её создателя. Команды указывают ферму по имени, а по UUID — только с флагом `--id`.
_Avoid_: Метка, псевдоним

**Профилирование**:
Наблюдение за изолированной от изменений игроками фермой, результатом которого является профиль производства.
_Avoid_: Профайлинг, замер КПД

**Профиль производства**:
Наблюдаемый состав предметов и скорость их производства автофермой без входа.
_Avoid_: КПД, характеристики фермы

**Создатель фермы**:
Игрок, разметивший ферму и имеющий исключительное право изменять её разметку и профиль производства.
_Avoid_: Владелец, администратор фермы

**Буфер выработки**:
Предметы, уже произведённые эмуляцией, но ещё не помещённые в выходной контейнер.
_Avoid_: Виртуальный сундук, внутреннее хранилище

**Снимок фермы**:
Сохранённое состояние блоков и сущностей исходного механизма, исключающее отдельный выходной контейнер.
_Avoid_: Структурный отпечаток, резервная копия мира

**Заполнитель**:
Блоки, временно занимающие область размеченной фермы вместо её исходного механизма.
_Avoid_: Филлер

**Стазис**:
Состояние размеченной фермы, в котором её исходный механизм заменён заполнителем, а производство заменено эмуляцией до явного восстановления.
_Avoid_: Заморозка, отключение фермы

**Эмуляция**:
Производство предметов по профилю без работы исходного механизма фермы.
_Avoid_: Симуляция, упрощённая ферма

**Нормализация предмета**:
Представление производимого предмета только его типом, без сохранения зачарований, прочности и других индивидуальных свойств.
_Avoid_: Эквивалентное преобразование, очистка предмета
